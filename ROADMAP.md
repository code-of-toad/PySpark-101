# PySpark 101 — Roadmap

## Purpose

This file is the canonical **progress tracker** for the PySpark 101 curriculum.

- `CURRICULUM.md` defines what must be learned.
- `WORKFLOW.md` defines how each phase should be completed.
- This file records what has actually been completed.

A phase should be marked complete only after its **mastery gate has been passed** and its end-of-phase handoff has been completed.
